# Riftforge Arena

Оригинальный браузерный прототип аренного шутера с видом от третьего лица. Включает тренировочную площадку, четыре детали строительства, локальное редактирование по клеткам при отпускании ЛКМ, оружие, манекены, настройки управления и необязательный сетевой сервер.

## Запуск

```powershell
npm install
npm run dev
```

Откройте адрес, выведенный Vite (обычно `http://localhost:5173`). Для сетевого режима во втором терминале запустите `npm run server`, затем нажмите «Сетевая игра». Для локальной тренировки сервер не нужен.

## Управление

- W / E / S / F — движение, Shift — бег, Space — прыжок, Left Ctrl — присесть.
- Mouse 5 / X / C / Mouse 4 — стена / пол / рампа / крыша. ЛКМ — размещение, R — поворот, M — материал.
- D — редактирование детали под прицелом. Зажмите ЛКМ, проведите по клеткам, отпустите для применения. Колесо вверх сбрасывает форму.
- 1 / 2 / 3 — оружие, A — инструмент, Q — переключение режима, ПКМ — прицел, Z — перезарядка.
- P — очистить постройки, Esc — меню. Все назначения и чувствительность меняются в настройках и сохраняются локально.

Прототип использует собственные примитивные модели и цвета. Сетевой сервер синхронизирует игроков и постройки, но не реализует полноценное клиентское предсказание, античит и серверную симуляцию боя.
